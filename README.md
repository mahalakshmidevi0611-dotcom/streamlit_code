# 💸 Daily Expenses Dashboard

An interactive and unique Daily Expenses Dashboard built using **Python & Streamlit**.  
This dashboard helps users track daily spending with a clean UI and sidebar menu navigation.

---

## 🚀 Features
- 📅 Track expenses by Date
- 🏷 Categories: Food, Travel, Shopping
- 💰 Total spending calculation
- 📊 Category-wise bar chart
- 🥧 Expense distribution pie chart
- ☰ Sidebar menu navigation
- ➕ Add new expenses dynamically
- 📈 Summary view for insights

---

## 🛠 Tech Stack
- Python
- Streamlit
- Pandas
- Matplotlib
